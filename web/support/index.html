Support

macOS 13 or later · Apple silicon and Intel

Strongcopy is a small open source project, and GitHub is where questions and bug reports are read and answered. There is no queue and no ticket number; issues are public, so an answer helps whoever asks next.

Report a problem Browse existing issues

A report is easiest to act on when it says which version of macOS you are running, which version of Strongcopy you have (click the menu bar icon and choose About Strongcopy), and what you expected to happen instead.

The badge is not appearing

Check that the clipboard icon is in your menu bar. If it is missing, Strongcopy is not running: open it from your Applications folder. On a Mac with a notch, a crowded menu bar can hide the icon behind it, in which case the app is running even though you cannot see it.

If the icon is there, remember the badge shows for eight tenths of a second beside the pointer and then disappears, so it is easy to miss while looking elsewhere on screen. Copy something and watch the pointer.

It does not seem to work in one particular app

It should work everywhere. Strongcopy watches the system pasteboard rather than intercepting Command-C, so copies made from menus, keyboard shortcuts, scripts, and password managers all count the same. An app where nothing appears is a bug worth reporting.

Does Strongcopy see what I copy?

No. It reads only the counter that macOS increments when the pasteboard changes, never the contents, and it makes no network connections. The privacy policy covers this in full, and the source is public so you need not take our word for it.

Starting Strongcopy with my Mac

Click the menu bar icon and choose Open at Login. macOS may ask you to approve the login item; if it does, allow Strongcopy under System Settings → General → Login Items.

Quitting and uninstalling

Click the menu bar icon and choose Quit Strongcopy. To remove it, turn Open at Login off first, then drag Strongcopy from your Applications folder to the Trash. It leaves behind no preferences or support files to clean up.

What Strongcopy needs

macOS 13 Ventura or later, on either Apple silicon or Intel. Builds are universal, so one download covers both. Strongcopy asks for neither Accessibility nor notification permission.

Anything else

Feature ideas, questions, and reports of things that read wrong are all welcome at github.com/mahata/strongcopy/issues.
